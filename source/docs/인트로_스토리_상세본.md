# 인트로 영상 스토리 — 상세본 (프롬프트 변환 전 단계)

원본 `인트로.hwp`의 4장면·대사는 그대로 유지하고, 프롬프트로 옮기기엔 부족했던 부분(구체적 동작, 카메라, 전환, 타이밍, 사운드)을 컷 단위로 채워 넣었습니다. 대사 변경은 없습니다.

## 전체 구성

- 총 러닝타임: 약 50~60초
- 장면 4개 → 컷 8개
- 색감 연출 축: 장면1(따뜻한 풀컬러) → 장면2~3(회색빛으로 채도 하락) → 장면4(다시 컬러 회복)
- 보물 탈취 연출은 실제 게임의 "보물도감 14칸" 개념과 연결해, 4곳(태극기 게양대·한글 간판·한복집 진열장·놀이마당)에서 각각 보물이 빠져나가는 것으로 구체화했습니다 (스테이지 1~4 테마와 자연스럽게 연결됨).

## 장면 1. 평화로운 시작 (컷1~2, 총 12~14초)

### 컷1. 마을 전경 (6~7초)
- 카메라: 하늘에서 마을 전체를 내려다보는 롱샷 → 서서히 마을 중앙 광장으로 트럭인(다가가기)
- 시간대/조명: 노을이 지기 시작하는 오후, 따뜻한 주황빛
- 배경: 기와지붕이 이어진 한옥마을. 대문 앞엔 태극기가 바람에 펄럭임. 담장 옆 화단엔 무궁화가 만개. 거리엔 간판을 단 상점 3곳 — "비빔밥·불고기" 식당, "식혜·수정과·인절미·한과" 카페, 한복집(진열장에 색색의 한복이 걸려 있음)
- 사운드: 잔잔한 국악 가야금 선율 페이드인, 새소리

### 컷2. 뛰노는 캐릭터들 (6~7초)
- 카메라: 광장 눈높이, 좌→우로 천천히 패닝
- 동작: 호랑이·곰·토끼, 남자아이·여자아이가 함께 있음. 화면 왼쪽에서는 두 명이 마당에 윷가락을 던지며 웃고, 오른쪽에서는 딱지치기 승부가 한창 — 딱지가 뒤집히는 순간 다같이 환호. 배경엔 지나가는 마을 사람들
- 사운드: 아이들 웃음소리, 딱지 치는 "탁!" 효과음, 배경 음악 유지

## 장면 2. 도깨비의 습격과 흐려지는 빛 (컷3~4, 총 11~13초)

### 컷3. 도깨비 등장 · 보물 탈취 (6~7초)
- 전환: 컷2에서 화면이 급격히 흔들리며 빠르게 전환 (놀란 분위기 유도)
- 카메라: 로우앵글, 마을 위 하늘 중심
- 동작: 하늘에 먹구름이 순식간에 몰려들며 번쩍이는 소용돌이에서 도깨비 무리(3~4마리, 각기 다른 색·무늬)가 낄낄대며 튀어나옴. 태극기 게양대·한글 간판·한복집 진열장·놀이마당 네 곳에서 반짝이는 보물 아이콘(보물도감 칸과 같은 모양)이 하나씩 두둥실 떠오르면, 도깨비들이 잽싸게 낚아채 사방으로 흩어져 도망감
- 사운드: 천둥 스팅, 도깨비 웃음소리("낄낄낄"), 음악이 긴장된 단조로 급전환

### 컷4. 색이 빠지는 마을 + 곰·토끼 반응 (5~6초)
- 카메라: 컷3에서 자연스럽게 줌아웃하며 마을 전체 → 곰과 토끼로 서서히 클로즈업
- 동작: 도깨비가 사라진 자리부터 마을 색이 순서대로 회색으로 빠짐 (태극기 색 바램 → 무궁화 시듦 → 간판 색 흐려짐). 곰은 두 손을 뺨에 대고 놀란 표정, 토끼는 귀가 축 처지며 불안한 표정
- 대사:
  - 곰: "앗! 장난꾸러기 도깨비들이 나타났어! 우리 보물들을 전부 빼앗아 가잖아!"
  - 토끼: "안 돼! 보물들이 사라지니까... 우리나라의 빛도 점점 흐려지고 있어!"
- 사운드: 음악 잦아듦, 낮은 저음 배경음

## 장면 3. 빛이 흐려지는 이유 — 핵심 메시지 (컷5, 총 7~8초)

### 컷5. 낙담한 호랑이·곰 클로즈업
- 카메라: 완전 회색톤이 된 마을 배경 앞, 호랑이·곰 얼굴 위주 투샷 클로즈업
- 동작: 둘 다 귀와 어깨가 축 처짐. 배경 저 멀리 구름 사이로 아주 옅은 빛줄기 한 가닥이 새어 들어옴 (다음 장면의 희망 복선)
- 대사:
  - 호랑이: "빛이 흐려진다는 건... 우리가 우리 문화의 소중함을 조금씩 잃어가고 있다는 뜻이야..."
  - 곰: "우리가 기억하지 않고 관심을 두지 않으면, 우리 문화는 힘을 잃고 영영 사라져 버릴지도 몰라!"
- 사운드: 잔잔하고 진지한 국악 저음 선율

## 장면 4. 결심과 수호대 출동 (컷6~8, 총 16~18초)

### 컷6. 세 캐릭터의 결심 (6~7초)
- 카메라: 로우앵글, 세 캐릭터를 아래에서 위로 담는 히어로 샷 구도
- 동작: 호랑이·곰·토끼가 나란히 서서 눈을 반짝이며 당당한 포즈(주먹 불끈, 가슴 펴기 등)를 취함. 발밑 바닥부터 색이 서서히 되돌아오기 시작
- 대사:
  - 토끼: "그럼 우리가 다시 기억해 내면 돼! 우리가 우리나라의 상징과 문화를 올바르게 알아갈 때마다 흐려진 빛이 다시 되돌아 올거야!"
- 사운드: 음악이 다시 밝고 힘차게 전환 시작

### 컷7. 되찾자 다짐 (5~6초)
- 카메라: 컷6에서 이어지는 투샷 → 호랑이로 클로즈업
- 동작: 마을 전체가 완전히 원래 색(따뜻한 노을빛)을 되찾음
- 대사:
  - 호랑이: "맞아! 미션을 성공해서 도깨비에게서 보물을 하나씩 되찾아 오자!"
- 사운드: 국악 크레센도

### 컷8. 시작 호출 (CTA) (5~6초)
- 카메라: 정면 풀샷, 세 캐릭터가 카메라(시청자)를 정면으로 바라봄
- 동작: 활짝 웃으며 손을 흔들어 시청자를 초대. 화면 하단에 여백을 두어 [활동 시작] 버튼 UI가 얹힐 자리 확보
- 대사:
  - 곰: "자! 우리 보물을 찾으러 우리랑 함께 할래? 그럼 시작 버튼을 눌러줘!"
- 사운드: 밝고 신나는 아웃트로, 버튼 클릭 유도 효과음

## 확인 부탁드릴 점

- 도깨비 마릿수(3~4마리)와 색·무늬는 제가 임의로 구체화한 부분이라, 원하시는 설정이 있으면 반영하겠습니다.
- 보물 탈취 연출을 4곳(게양대·간판·진열장·놀이마당)으로 나눈 건 스테이지 4개 테마와 연결하려는 의도인데, 이 방향이 맞는지 확인 부탁드립니다.
