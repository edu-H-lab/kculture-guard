우리 문화 수호대 — AI 포함 로컬 실행 안내
===================================================

이 프로그램은 두 가지 방법으로 실행할 수 있어요.

[방법 A] AI 없이 실행 — program\1_실행하기.bat
  - 설정 없이 바로 실행됩니다. (http://localhost:8756)
  - 생각친구는 정해진 질문과 정리 문장으로 동작합니다.

[방법 B] AI 포함 실행(권장) — program\2_AI포함_실행하기.bat
  - 생각친구가 학생 답변에 맞춰 AI로 대화하고,
    교사용 AI 분석 버튼까지 사용할 수 있습니다.
  - 아래 순서대로 한 번만 설정하면 됩니다.

--------------------------------------------------
[AI 포함 실행 — 최초 1회 설정]
--------------------------------------------------
1. Node.js 설치 (이미 설치되어 있다면 건너뛰기)
   https://nodejs.org 에서 "LTS" 버전을 내려받아 설치합니다.

2. Gemini API 키 발급 (무료)
   https://aistudio.google.com/apikey 접속 → 구글 계정 로그인
   → "Create API key" 클릭 → 키 복사

3. source\server\.env.example 파일을 같은 폴더에 복사한 뒤
   파일 이름을 ".env" 로 바꿉니다.

4. .env 파일을 메모장으로 열어 두 줄을 수정합니다.
      THINKING_FRIEND_PROVIDER=gemini
      GEMINI_API_KEY=여기에_발급받은_키_붙여넣기
   저장 후 닫습니다.

5. program\2_AI포함_실행하기.bat 을 두 번 누릅니다.
   → 검은 창이 뜨고 잠시 뒤 브라우저에 http://localhost:8780 이 열립니다.
   → 이 창을 닫으면 프로그램이 멈춥니다.

--------------------------------------------------
[자주 묻는 질문]
--------------------------------------------------
Q. bat 파일을 눌렀는데 AI 없이 실행돼요.
A. .env 파일 이름/위치, GEMINI_API_KEY 값, THINKING_FRIEND_PROVIDER=gemini
   설정을 다시 확인하세요. Node.js 가 설치되어 있는지도 확인하세요.

Q. node_modules 가 이미 들어있는데 npm install 을 또 해야 하나요?
A. 아니요. source\server\node_modules 가 이미 포함되어 있어
   바로 실행됩니다.

Q. 인터넷이 안 되는 곳에서도 실행되나요?
A. 방법 A(AI 없이)는 인터넷 없이도 실행됩니다.
   방법 B(AI 포함)는 Gemini 서버와 통신하므로 인터넷이 필요합니다.
